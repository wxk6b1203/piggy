## 2. 逐项裁决（采纳 / 改造 / 不采纳）

### 2.1 采纳（已排期）

| DSH 能力 | Piggy 落点 | 排期 |
|---|---|---|
| **对话 \\| 轨迹 二级页签** | 会话 tab 内页签；轨迹 = 全事件回放（数据源 `get_entries` + 实时事件，04 §1.10） | M1 |
| **轨迹事件流**：轮次分组、角色芯片（系统/用户/上下文/助手/工具）、工具行 `args → result` 可展开、过滤 + 搜索 | 04 §1.10 事件流列表；角色芯片 ours 增加 压缩/label/分支 | M1 |
| **三轨时间线**（输入/模型/工具甘特全景）+ 状态行 `N 轮 N 步 · tok/s` | 04 §1.10 时间线；Rust 事件信封加单调时间戳 `t` | M2 |
| **本轮文件改动 chips**（消息下方的文件链接行） | 右栏"变更"视图的行内前置：回合级 changeset chips（数据同源：edit/write 工具调用聚合），点击开 diff 预览 | M1 |
| **会话侧栏**：工作区分组 + 相对时间戳 + 选中高亮 + "展开其余 N 个"折叠 | 左侧栏会话视图（04 §1.5）——分组/时间戳/折叠语义照收 | M1 |
| **消息操作行**（复制/反馈 + 用量/用时统计） | MessageView 底部轻量操作行（复制全文、用量/用时；反馈按钮 M2+） | M1/M2 |
| **状态行**（轮/步 · tok/s · 总 tok · 缓存命中） | 状态栏扩展（缓存命中率来自 usage.cacheRead，05 预算内） | M1 |
| **Composer 细节**：占位提示含 `/ 指令`、`@ 文件`；模型胶囊（名+thinking 级）；上下文环 | Composer M1 版：斜杠补全已有规划（04 §7），模型胶囊 = `Cmd+L` 选择器的常驻入口，上下文环 = contextUsage%（右栏统计的同源迷你版） | M1 |
| **右侧代码预览面板**（tab + 面包屑 + 语言条 + 行号高亮） | 编辑区预览 tab（Monaco）+ 右栏文件视图（04 §1.6）；面包屑/语言条/复制为预览 tab 标配 | M1 |
| **"打开方式"外部应用菜单**（Finder/VS Code/iTerm…） | **已做**：会话头部右侧分裂胶囊（主按钮 = 上次用过的应用，箭头 = 本机全部可用）。宿主半边在 Rust（`open_in_app`，移植 `dsh-host-open-in-app` 的目录/解析/图标/启动），不引入 `tauri-plugin-opener`（见 03 §2.11）。文件级那档也做了（预览头部：系统默认应用 / 处理器菜单 / 显示文件位置），见 03 §2.11 的 `paths.rs` | M1 完成 |

### 2.2 改造（意图保留、形态不同）

- **DSH 右侧面板 = 固定代码预览**；Piggy 用**右侧栏多视图 + 编辑区预览 tab**（04 §1.6）——因为 Piggy 的右栏还要承载 变更/子代理/会话树/统计/Widgets，单一预览面板不够用；
- **DSH 的"标准模式"胶囊**（权限/沙箱选择）→ Piggy 不自建沙箱语义，映射为 pi 的工具集/信任配置入口（M2 评估：`--approve` 等价的会话级开关）；
- **@ 文件引用**：DSH 在输入框提 @ 文件；Piggy 对应 `@path` 展开为附件文本（pi 的 attachments 语义），M2。

### 2.3 不采纳

- 顶部无标题栏的 Web 布局（Piggy 是桌面应用，保留系统标题栏 + 自绘状态区）；
- 消息 👍/👎（无训练回路，无收益）；
- "HARNESS" 徽标式品牌行（Piggy 保持极简 logo）。

## 3. 事实核对提醒

原说明文档明确标注了推断项（图标语义、坐标近似）。已核实的关键差异：

- dsh_3 状态行"1 轮 29 步"中的"步"= 工具调用次数 + LLM 调用次数的和（Piggy 分别计数：`tool_execution_*` 与 turn 数）；
- DSH 轨迹含"上下文"行（runtime context 快照注入）——对应 pi 的 AGENTS.md/上下文文件注入，Piggy 的轨迹行类型加"上下文"芯片（数据：system/上下文类 message）。
